# EMLP-D2: deletion changes direction, not just amplitude

2026-10-28. Completes the fixed norm control proposed after D1. Same160 opened task endpoints,
same four quarter masks and two half masks, no ranking, refit, new prompts or gain optimization.

For native MLP1 write y and literally deleted write d, compare D1's d with
`c = y * ||d|| / ||y||` independently at each position. Bias is included in both writes.
Thus c retains the native direction at exactly the deleted write's magnitude. If both norms are
zero, c is zero; a zero native norm with nonzero deleted norm aborts as undefined. No such zero
case occurred. This control computes the intact model's write and is **not a pruned implementation**.

## Interpretation

An amplitude-only account of deletion damage is insufficient. The removed products also change
write direction; those changes have larger output consequences than reducing the native write
to the same norm. Even cosine around.94 is not enough to ensure output fidelity. This is a useful
constraint for featurizers: reconstruction should preserve downstream-relevant directions, not
just activation magnitude or binary task labels.

It remains incorrect to conclude that the channels encode independent, necessary features.
Deletion tolerance may involve overlapping contributions, downstream insensitivity or compensation.
Nor can KL(deletion)−KL(control) be called the unique fraction attributable to direction: the
network and metric are nonlinear. D2 does not evaluate deleted direction restored to native norm,
so it makes no claim that magnitude restoration would repair a pruned model.

D1 and D2 jointly show partial robustness of task decisions, measurable distributional damage,
and sensitivity to the direction of the remaining write. They do not show exact duplicate
subcomputations, a faithful removable subspace, or corpus-wide approximate equivalence.

## Next boundary

Stop expanding this authored panel or searching masks. Before a corpus-wide removability claim,
audit the available natural-text row manifests and prior-use records. Freeze a finite evaluation
cohort, the same existing masks and controls, and metrics before running. Explicitly label any
previously used documents as reused; if disjointness cannot be established, do not call them fresh.
Report document-level and position-stratified KL, native-top1 agreement and observed-token CE;
retain per-document tails, and distinguish early prompt positions from later ones. No fidelity
threshold should be chosen after seeing that evaluation. The present result remains descriptive.
This corpus check would test whether the deletion pattern survives beyond short task prompts;
it is not permission to optimize or sweep native-channel rankings.
