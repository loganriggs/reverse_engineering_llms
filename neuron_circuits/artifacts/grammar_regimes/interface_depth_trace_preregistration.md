# Preregistration: where rule-specific computation becomes an answer interface

The final-layer red-team found nearly identical semantic-rule and generic
answer-transition effect directions. Norm matching largely or completely closes
their behavioral gap. This implies that rule-specific evidence may be computed
upstream and converted into a generic output verb late.

Repeat the exact disjoint-identity/template assay at every MLP layer of the seven
gate-passing depth-4 bilinear checkpoints. At each layer:

- learn eight answer-class activation prototypes from unrelated correct facts;
- learn direct-rule semantic deltas from paired latent counterfactuals;
- patch each delta into the same held-out semantic recipients;
- measure exact target accuracy, softmax-Fisher effect cosine/fidelity, native
  top-32 support overlap, and native-versus-rotated finite performance;
- independently measure generic class-prototype transfer on held-out facts.

No scaling is applied in the primary depth trace: the question is where effect
direction and native support become shared. Fully arbitrary checkpoints enter
only the generic answer-interface comparison. Underfit seed-2 mixed/arbitrary
checkpoints remain excluded.

A rise from rule-specific upstream directions to a shared final effect supports
an encoder/computation-to-output-interface pipeline. High cosine at every layer
would instead say that the declared semantic patch never isolated the rule
computation. Weak cosine at every layer would reject the generic-interface
interpretation of the final result.
