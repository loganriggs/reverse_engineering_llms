# Preregistration: codebook factorial in MLP-write space

The same-manifest experiment found an adjudicative, causally transferable Layer-3
write space after quotienting bilinear channel symmetries.  This matched test uses
the three original pure-rule models whose grammar is identical but whose random
answer permutations differ.

For each ordered pair and omitted direct relation, fit the identical write-space
alignment on the other seven relations.  Because the omitted relation's answer
permutation is independent across source and target, a universal semantic
coordinate system could still align it, whereas a codebook-relative output
interface should not.

The target model's own generic answer edit is an internal positive control.  Its
success does not validate cross-model alignment; it asks whether the local final
interface remains present even when its coordinates cannot be inferred from a
different codebook.
