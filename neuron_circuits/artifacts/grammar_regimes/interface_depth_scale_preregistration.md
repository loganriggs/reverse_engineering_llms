# Preregistration: calibrated depth boundary of the grammar output interface

The unscaled trace showed semantic/answer effect cosine rising from 0.868 at
Layer 1 to 0.924 at Layer 2 and 0.992 at Layer 3 in pure-rule models. Layer 0
patches have nearly zero effect, making relative fidelity there ill-conditioned;
it is excluded from the primary boundary test.

At Layers 1–3, recreate the disjoint semantic and class-prototype deltas. Match
the generic answer delta to the semantic activation norm, and independently
select one scalar from the frozen grid using only discovery-template margin
effects. Freeze the scalar and evaluate exact patches on held-out identities and
template 6.

The earliest layer whose scaled generic answer patch matches both semantic
behavior and softmax-Fisher effect is the measured output-interface boundary.
Before that boundary, failure after scalar calibration is evidence for a
rule-specific direction or state dependence. Layer-0 relative scores remain
descriptive only because their target effects are too small.
