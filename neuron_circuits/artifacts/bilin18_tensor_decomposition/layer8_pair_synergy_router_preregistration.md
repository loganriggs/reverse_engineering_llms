# Preregistration: second-order suffix-path grammar

Singleton downstream fingerprints cannot encode that enabling one attention
Jacobian changes the tangent entering another. For every layer pair define the
exact softmax-Fisher response synergy

`S_lm = R_{l,m} - R_l - R_m + R_empty`.

The site fingerprint contains invariant within-site ranks/standardized values
for singleton response norms, pair-synergy norms, and pair-response norms, plus
the signed cosine between each synergy and the sum of its singleton
corrections. A candidate triple sees only the singleton features for its three
layers and pair features for its three constituent pairs, along with static
mask bits.

No triple response, full nine-layer response, or finite intervention enters the
feature extractor. Ridge strength is selected by query-grouped FineWeb
validation and frozen for WikiText. A seeded site shuffle is the dynamic-feature
control.

Validation requires median >=0.95 and 10th percentile >=0.80 on both corpora.
Added value requires +0.10 lower-tail fidelity over the best invariant
singleton fingerprint on both. Failure rejects a second-order layer-level path
grammar, not head-level or third-order structure.
