# Preregistration: causal compilation depth of the Layer-17 operator router

The final-boundary source intervention established that native token embeddings
predict the compact operator, while the carried residual—not the direct final
embedding injection—is its causal carrier. This experiment asks when that
predictive lexical geometry becomes causally committed to the carried stream.

Two measurements are kept separate at every block boundary:

1. **Predictive chart.** Fit a discovery-frozen ridge map from the current-position
   carried state to the final rank-16 context register. Also fit a map using only
   its projection into the tensor context span and retain the native-embedding
   chart as a baseline.
2. **Finite causal cut.** Replace the current-position carried state by its
   position-conditioned discovery mean or a cyclic donor, then recompute every
   remaining block, embedding reinjection, attention operation, MLP, and the
   final local operator. The persistent Layer-0 value bus and original embedding
   remain native.

Predictive maps use all boundaries and larger held-out panels. The more costly
finite trace uses ten preregistered boundaries, four positions, and three
corpora. A matched response-permutation control is fit at Layer 16. The first
tested depth below 0.90 mean-replacement fidelity is descriptive evidence for a
commitment boundary, not an anatomically sharp phase transition.

High decodability with weak causal sensitivity means that later computation can
reconstruct the code. High decodability and strong causal sensitivity means the
state has become an indispensable carrier under this cut. Neither alone proves
that a layer stores a mutually exclusive fraction of the computation.
