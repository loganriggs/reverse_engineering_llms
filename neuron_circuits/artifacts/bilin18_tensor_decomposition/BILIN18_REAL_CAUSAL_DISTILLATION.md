A posthoc exact output-space diagnostic clarifies the failure. Even an oracle choosing the BEST64-dimensional output subspace on the evaluation effects has79.57% relative error;314 dimensions are required to capture90% of effect energy on this panel. Because each student's finite changes lie in its fixed64-dimensional output span, this is a hard lower bound for that architecture on these cached effects. Actual learned spans, with oracle true coefficients, give92.69–92.75% error. Thus both global capacity and learning the right span/coefficients are problems; a different causal loss alone cannot make this64-output-rank architecture faithfully reproduce arbitrary random responses. The rank bound is local-update geometry, NOT a lower bound on downstream KL or meaningful task computation.

This does not show that the model lacks compact units. Many reusable units can jointly produce high-rank responses, context can select different output directions, and random perturbations may emphasize behavior irrelevant to the tasks of interest. Nor does it reject an overcomplete dictionary with sparse per-example use; this student has only64 total output directions. Next evaluate known agreement/sentiment relay contrasts as independent held-out mechanisms and measure whether the relevant effects are actually low-rank before choosing a broader or conditional representation. Preserve independent random probes as a generality check and full-model output fidelity as the eventual criterion.
