# Preregistration: analytic bilinear router for the compact boundary module

The fixed boundary-write subspace transfers out of distribution, but a linear map
from state change to coefficients does not fully route it on WikiText.  In a
bilinear MLP the exact activation change has a known decomposition.  For base
normalized state `s` and counterfactual change `d`,

`h(s+d)-h(s) = L(s)R(d) + L(d)R(s) + L(d)R(d)`.

The first two terms condition the edit on the current state; the last depends only
on the edit.  This assay projects their residual writes into the frozen rank-32
FineWeb boundary subspace and evaluates finite full-vocabulary effects.

To test whether the base/edit pairing matters rather than only norms, shuffle base
states across examples inside each evaluation corpus, recompute the two cross
terms, and norm-match each shuffled write to the correctly paired cross write.
The analytic identity is checked before causal interpretation.

Finally, decompose the projected coefficient vector into native-channel
contributions and report absolute-contribution effective support.  A compact
output module with broad channel support is a concrete instance of a simple
effect-space verb implemented by a distributed bilinear router.
