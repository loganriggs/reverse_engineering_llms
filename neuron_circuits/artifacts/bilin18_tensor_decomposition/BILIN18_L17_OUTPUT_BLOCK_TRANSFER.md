**Interpretation.** Equal-sized cross-evaluation removes the earlier768-versus256 size difference from the within/cross-block comparison. Within-block capture is optimistic because those same data determine the basis; cross-block capture measures transfer. A persistent gap is consistent with high-dimensional covariance estimation and context variation, not by itself a proof of semantic context dependence. The nested curve tests whether more data improves transfer within this fixed geometry. One nested ordering and one fixed target block do not establish an asymptotic learning law or population ceiling.

No new compact semantic unit or executable response predictor follows from output projection. A response can have broad output covariance even if generated by an economical nonlinear rule. Conversely, a compact empirical output space would not establish a compact input computation.

**Audit.** Summed first-three-block moments and fourth-block moments reproduce H304 train/validation moments within relative1e-5 (maximum absolute difference normalized by maximum absolute original entry). Same frozen response construction and document ordering. Saved block moments allow later diagnostics without model reruns. Native computation remains float32, covariance/eigensolves float64. No model weights changed, no new fresh documents, all jobs terminal.

**Next discriminator.** Fit a finite-sample null with broad shared covariance and the same samples per block, then compare its in-sample inflation and transfer gap with the observations. This tests whether ordinary sampling noise can account for the apparent context variation before inventing context labels. Preserve group energies and sample counts; treat a Gaussian null as a narrow control, not a realistic language model. Broad research goal remains active.
