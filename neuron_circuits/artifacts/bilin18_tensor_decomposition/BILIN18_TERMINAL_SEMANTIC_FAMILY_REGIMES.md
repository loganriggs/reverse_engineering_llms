## Interpretation boundary

These human-declared families were fixed before this terminal experiment, but they differ in frequency, grammatical role, pair count, and contextual naturalness. A family-level k90 advantage supports a relation-conditioned regime; it does not show that human semantic coherence itself causes sparsity. The terminal post-boundary branch remains only one part of each full natural edit.
