# Preregistration: pooled late edit backbone

Operation-specific rank-32 bases and top-128 channel banks overlapped strongly,
and cyclic wrong-operation objects were almost as causal as the correct ones.
This favors a generic late edit backbone over four separate modules.

Concatenate FineWeb discovery write changes for newline, period, comma, and ` the`.
Fit one uncentered write basis with ranks 16, 32, 64, and 128.  Rank native channels
once by average absolute contribution over all four operations to the pooled
rank-128 coefficient space.  Freeze the basis and channel ordering.

For each operation and held-out corpus, compare pooled bases with the operation's
target-specific basis and an equal-rank random basis.  Compare pooled channel banks
with target-specific banks and a fixed random bank.  A pooled success would locate
a general final-MLP edit interface; it would not imply that upstream evidence or
the coefficient router is shared.
