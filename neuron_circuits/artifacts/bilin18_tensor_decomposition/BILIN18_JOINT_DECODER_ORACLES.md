## H990 — Learned decoder coverage and encoding both fail; train-only PCA is a stronger local baseline

Previous turn was progress: H989 integrated expanded context data into sixteen new joint models and evaluated eight frozen baselines. This turn distinguishes decoder-span coverage from encoder/support error using all24 frozen models, rather than another objective sweep.

For every evaluated pair, compare actual encoded donor-minus-recipient reconstruction with the least-squares projection of the TRUE write difference into (a) all128 decoder atoms and (b) the union of the recipient/donor gates' actually selected atoms. These are teacher-informed diagnostic ceilings. Union-support projection is permissive: it may assign coordinates differently for each evaluated pair and does not define consistent single-state coordinates. Its gap to encoded error combines coordinate-inference and pair-consistency limitations; it cannot isolate a particular encoder defect. Full-span minus union-span performance diagnoses the limitation of the current selected supports.

PCA controls fit centered training states only, with32 or up to128 components, capped at numerical rank using singular-value threshold1e-6 relative to the largest. They are ordinary frozen linear projection baselines, not teacher-fitted oracle coefficients: projecting a difference equals subtracting separately projected states. No validation labels or differences fit their basis. The dense-coordinate budget differs from group sparsity. Frozen small6 has rank40, expanded6 rank131 and expanded7 rank139, consistent with unique-prompt counts minus one; PCA128 on small6 actually has40components. PCA bases are shared across seeds/objectives within each data regime, so duplicated scores are not independent replicates.

The original H989 coverage conclusion needs qualification: more context data helps a train-only linear subspace substantially (PCA128 context error0.351→0.218; holdout0.946→0.842), even though the trained sparse models did not realize consistent gains. The data contain useful transferable geometry. The learned dictionary, its sparse supports and coordinate encoder each leave avoidable local error under these controls.

For familiar-task new contexts, full learned decoder-span errors around0.51–0.53 in expanded6 pair models are worse than PCA32 at0.332, despite the dictionary having128 available directions. Selected supports raise the floor to0.65, and actual encoding to1.11. Thus inference alone cannot reach the PCA baseline while retaining those learned decoder spans. Random initialization/optimization, objective and sparse constraints remain competing explanations; this does not prove intrinsic inferiority of block or shared-group representations.

Whole-task holdouts expose a different dominant limitation: full learned spans still leave~0.88error, and selected supports~0.97. Even perfect coefficients on the current supports could preserve little of these unseen-task changes in Euclidean norm. PCA128 improves to0.842 but is still weak. This is evidence for missing representation coverage at this site/training distribution, not evidence against all reusable computation in the model. Activation error does not establish behavioral loss.
