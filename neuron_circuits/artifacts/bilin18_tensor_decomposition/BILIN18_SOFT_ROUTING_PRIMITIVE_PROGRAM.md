# Soft routing-variable program

NMF token memberships are normalized to a partition of unity and executed directly. Each edge is fractionally assigned to variables; selecting a `(head, distance, variable)` type retains that membership fraction. All types must therefore exactly recover native attention. The route supports are selected from soft grouped operator effects on discovery.

Maximum native-branch error: `5.39e-05`. No-attention baseline KL: `7.110`.

## Guardrails

Soft types are more expressive than hard types because a token edge can be partially retained by several variables. The comparison holds the number of selected `(head, distance, variable)` predicates fixed, not the number of nonzero edge memberships or arithmetic operations. NMF membership values are real numbers and therefore cost more to describe than a categorical dictionary unless quantized or generated by a shorter rule. High causal fidelity alone does not establish MDL superiority or readability.
