# Preregistration: multi-operation late write modules

The newline edit has a compact rank-32 write module and a useful fixed native
channel bank.  This could be a general late-interface organization or a special
document-boundary circuit.

Repeat the same final-MLP-path assay for current-token replacement by newline,
period, comma, and the common token ` the`.  For each target, learn on the same
FineWeb discovery rows:

1. an uncentered rank-32 basis of exact final-MLP write changes; and
2. a fixed top-128 native channel set ranked by mean absolute activation-change
   contribution to that target's rank-32 coefficients.

Freeze these objects and evaluate on new FineWeb, WikiText, and TinyStories rows.
Compare each target with an equal-rank random subspace, a cyclic wrong-target
subspace, a fixed random channel set, and a cyclic wrong-target channel bank.

Correct subspaces use oracle coefficients in this assay; they test whether the
operation-specific span exists, not whether a router has been solved. Correct
fixed channel banks use the naturally computed activation changes and therefore
test reusable native implementation.
