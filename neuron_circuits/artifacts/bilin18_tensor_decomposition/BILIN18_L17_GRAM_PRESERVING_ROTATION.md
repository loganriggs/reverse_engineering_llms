

## H399 — Does source orientation matter after fixing joint geometry?

All36 L17 head pairs, actual sources and six joint-geometry-preserving rotations, four amplitudes(1,1),(1,−1),(4,4),(4,−4), same512 reused H390 documents/2,048 sites. This replaces H398 within-head-span moment controls with random residual-space orientations. The intact state and MLP weights remain fixed. Controls are counterfactual residual directions, not natural attention-head outputs.

Construction at each site: normalize the pre-MLP residual p to unit u. Split all nine source vectors into parallel components and perpendicular columns V. Form G=VᵀV. Draw a Gaussian1152×9 matrix, project it orthogonal to u, and QR-factor it with positive diagonal convention to obtain a random orthonormal frame Q. Replace V with Q*sqrt(G), using the symmetric positive-semidefinite square root, and restore each original parallel component. This maps the complete nine-source configuration by an isometry fixing p, preserving every source norm, source–residual dot product and source–source dot product. A different random orientation is used per recipient site and draw; this does not test a single globally rotated coordinate system. Construction uses float64; audit the delivered float32 vectors.

Raw targets are the exact rational joint law; predictions sum single-source rational laws. Direct finite native responses are audited at four fixed sites per pair/condition/amplitude. Primary error is squared raw composition error divided at each site by the intact final-state squared norm, then averaged. This common scale is identical between actual and rotated conditions. Separate relative-error fractions divide pooled composition error by pooled joint-response squared norm. No native output KL is measured in this experiment.

Outcome: geometry, actual replay, native arithmetic and ordinary-amplitude raw unit99 gates all pass. The strong-candidate gate passes; the weak-candidate gate fails. Maximum normalized source-Gram discrepancy after float32 conversion is3.57e-8 and maximum normalized residual-dot discrepancy2.42e-8. Actual raw error/effect arrays replay H398 exactly. Thus differences are not explained by changed source norms, mutual angles, residual angles or input RMS denominator geometry, to the stated numerical precision.

Actual/rotated common-scale error ratios range0.7949–5.5612. Of144 pair/amplitude contrasts,108 have simultaneous lower bounds above1,33 above2, none have upper bounds below1, and none below0.5. Learned source orientation often produces more raw composition error than random orientations with the same complete input geometry. This is evidence of orientation dependence relative to the MLP weights, not evidence that natural sources form unusually independent units. Ordinary-amplitude squared relative errors remain small for both families: maximum point0.2991%, maximum simultaneous upper0.3421%. The rotated controls therefore also exhibit approximate additivity at ordinary amplitudes.

Important competing explanation: learned directions may simply have higher MLP response gain. For heads1/8 at the selected condition, common-scaled joint effect energy is0.03070 for actual versus0.006572 for rotations (ratio4.671), alongside error ratio5.561. For heads6/8, effect energy0.08868 versus0.019714 (ratio4.498), alongside error ratio4.884. The ordinary pooled error/effect fractions are0.4892% actual versus0.4033% rotated for1/8, and0.4605% actual versus0.5604% rotated for6/8. Thus a large common-scale error excess does not imply a large excess of relative nonadditivity; the6/8 ordering reverses when normalizing by joint effect energy. Common-scaled and unscaled pooled energy ratios weight contexts differently, so they should not be interchanged algebraically.

Hypothesis update: input Gram geometry alone does not determine raw interaction size; orientation relative to the learned bilinear map matters. Generic high-dimensional near-additivity at ordinary amplitude remains supported. Specially weak coupling of natural sources is not supported by this rotation test. General response gain, selective bilinear cross-coupling and context-dependent cancellation are the remaining leading explanations for the selected large-amplitude excesses. None yet identifies a semantic feature or a reusable compressed computational unit.
