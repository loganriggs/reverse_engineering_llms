## H741 — The operation-linked sign is carried by a joint second-query/second-key relation

We crossed the four post-normalization, post-rotary components of L13H0's routing coefficient between matched binding/copying contexts: q1, k1, q2 and k2. All sixteen recipient/donor combinations were evaluated, with no selection of successful hybrids. Source/final tokens and positions remain exactly matched as established in H740.

The coefficient is alpha=lambda*(q1·k1/128)*(q2·k2/128). A hybrid coefficient replaces only the designated source-to-head bus contribution; other edges, local values and downstream computation remain native. This is a surgical single-edge intervention, not replacing all uses of a query or key or the upstream residual stream. Original source values are held fixed for one test; a separate test uses the same three absent-token pairs across every hybrid.

There are 64 directed exchanges from 32 matched context comparisons. One matched comparison already has the same native sign on both operations, leaving 62 directed exchanges with opposite native signs. Sign-transfer counts below use those 62; all 64 remain in the saved data.

| Donor components exchanged | Transfers donor coefficient sign |
|---|---:|
| q1 only | 0/62 |
| k1 only | 0/62 |
| Both components of factor 1 | 0/62 |
| q2 only | 39/62 |
| Both queries | 39/62 |
| k2 only | 23/62 |
| Both keys | 23/62 |
| Both components of factor 2 | 62/62 |
| All four components | 62/62 |

The first dot-product factor is positive in all native primary contexts, ranging approximately 0.35–0.67. The second factor is positive for binding (approximately 0.09–0.32) and usually negative for copying (approximately -0.15 to -0.027 narrative; -0.117 to +0.011 list). Its one list-copy exception reproduces H740's exception. Exchanging factor 2 transfers the sign completely, while the retained recipient factor 1 still changes its magnitude: coefficient RMS error relative to the all-donor coefficient remains approximately 21–30% across the four receiver cells. Thus factor 1 contributes gain even though it does not control this sign contrast.

The component effects are asymmetric:

| Receiver cell, donor is opposite operation | q2-only sign transfer | k2-only sign transfer |
|---|---:|---:|
| Narrative binding | 3/16 | 1/16 |
| List binding | 6/15 | 0/15 |
| Narrative copying | 15/16 | 13/16 |
| List copying | 15/15 | 9/15 |

A binding donor component often makes a copying receiver positive; a copying donor component alone usually does not make a binding receiver negative. Both copying-side components are generally needed. This supports a relational computation involving both contextual states, rather than a clean one-location operation bit. It does not yet identify which directions encode that relation or where those directions were formed upstream.

The surgical coefficient changes have the predicted downstream sign. Across all sixteen hybrids plus the reversed-native control, the fixed-map prediction matches all 3,264 nonzero absent-token contrast signs (64 contexts x 17 conditions x three fixed pairs). Zero-coefficient contrasts are exactly zero. These are correlated tests using reused contexts and three token pairs, not independent population trials. Original-source-value interventions and their intended-answer margin changes are also recorded; sign transfer is not claimed to solve the whole task or establish edge necessity.

Audits: native final-logit replay maximum error was 1.19e-5; native coefficient replay error 9.84e-7; the all-donor coefficient exactly matches the donor coefficient. Native-value identity margin error was at most 5.72e-6; native/zero/reversed absent-token effects replayed H740 within 3.58e-6. All hashes remained unchanged and results were finite. The experiment completed 8,000 full-model example forwards with no new natural documents or original reserved-test evaluations.

Interpretation: a candidate reusable unit is now more concrete than a sparse decoder atom: a signed bilinear relation between a contextual destination query and contextual source key, controlling a fixed token/value map. This is evidence about this head, these matched contrasts and this source edge. It is not a universal operation taxonomy, nor evidence that every relevant state lies on a verified low-dimensional manifold.

Next: test whether the q2/k2 operation edits can be captured in low-dimensional reproducible subspaces. Fit paired edit bases using a fixed subset of names, then project donor-minus-receiver edits on held-out names, separately for queries and keys, with equal-rank random-subspace controls and full-rank identity. Retain both formats and reciprocal exchanges; distinguish preservation of coefficient magnitude from merely its sign. Account explicitly for rotary position when comparing formats. This is a supervised paired-edit diagnostic on a reused panel, not unsupervised discovery or fresh confirmation. A successful compact subspace would then need fresh contexts and causal validation before a manifold claim. Sentiment's format/content diagnostic remains outstanding.
