# Separating untouched natural background from diagnostic rule edits

The earlier [joint FineWeb pilot](CORPUS_SURNAME_JOINT_MODEL_AND_OV.md) described its background rows as ordinary prose. Its cache builder actually drew those rows from a document sampler with 50% conditional list-shift and square-bracket edit probabilities. The edits were rare, but that wording overstated the purity of the natural-language background control. This correction adds an explicit `--unedited-background` option: ordinary background chunks come from unchanged source text; task-enriched bracket/list rows and paired surname edits continue to use the original diagnostic draws. Source-level hash/near-duplicate filtering and split membership are unchanged.

Rebuilding the same 10,000-train/972-validation/1,028-test source cache gives **zero changed background documents** under the corrected option. The diagnostic sampler changes 750/10,000 train, 74/972 validation, and 83/1,028 test documents before chunk selection. Relative to the old cache, 395/10,000 train, 40/972 validation, and 46/1,028 test selected background chunks differ. Every task-specific row, including both surname arms and bracket/code/style/list strata, is byte-for-byte identical across caches. The corrected cache and source prose remain local; the [manifest](results/corpus_surname_joint_unedited_background_train10k_test2k_manifest.json) records the law and counts.

The [paired checkpoint evaluation](results/corpus_surname_joint_unedited_background_checkpoint_eval.json) scores the previously trained depth-2 baseline and paired-surname models on both cache versions. On the standard first 128 test background rows, baseline NLL is **7.4351 old / 7.4327 unedited**; paired model NLL is **7.4310 / 7.4297**. On the 46 changed test rows alone, baseline NLL is 7.3024 / 7.2383 and paired NLL is 7.3046 / 7.2665. The changed rows can have different BPE targets, so this is a distribution-correction check, not a paired causal-effect measure. The task behavior reported earlier remains attached to identical task rows, but the old background NLL should be labeled as *mostly natural, partly edited*.

Because only 3.95% of training background chunks differ and the heldout 128-row NLL change is small, a fresh 6,000-step run on the same 10,000 sources would have low information value. The next training distribution will use more independent natural sources, keep its background unedited, and expose task enrichment and counterfactual site weighting as separate sampling parameters. A source-disjoint evaluation panel and task-window form audit remain necessary before making stronger realism or circuit claims.
