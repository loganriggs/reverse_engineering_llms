# Joint corpus-rule DGP V2: controllable incidence and coupling

This is a **semi-parametric** sampled language process. An empirical FineWeb source document is sampled without replacement; four local rule gates then select eligible list, bracket, literal-copy, and spelling-style sites. The source distribution supplies ordinary language form. The [sampler](corpus_rule_mixture_dgp.py) records source identity, eligibility, active gates, and selected rule sites. It does **not** provide a symbolic next-token oracle for untouched source prose, or make the semantic proposition generator realistic. This is a controlled natural-carrier arm for later bilinear and weight-method comparisons, not a replacement for the fully sampled semantic-language track.

Two independent controls are explicit. `source_policy=uniform` samples distinct documents from a fixed source panel; `multitask` first requires at least two of the four eligible families. `gate_rate=p` sets each rule's marginal activation probability when eligible. `coupling_strength=c` samples an unobserved document-level rich/lean state, then uses conditional probabilities `p+c` and `p-c` for **every** gate, drawn independently given that state. Thus each gate still has marginal probability `p`, while two jointly eligible gates have joint activation probability `p²+c²` under the specified law. The rich/lean state changes task co-occurrence, not the task answer rule or the source text. This is *prevalence coupling*, not a learned shared computation or an interaction in the semantic rule itself.

An [implementation check](audit_corpus_rule_mixture_law.py) replayed 5,000 draws of one source eligible for both bracket and literal copy. At `p=.5`, independent/coupled (`c=0/.4`) bracket activation was .507/.486, literal activation .498/.496, and joint activation .248/.398. The theoretical joint probabilities are .25/.41. The [aggregate result](results/corpus_rule_mixture_gate_law_5000.json) includes the source hash and specified law. Each draw's gates are sampled before candidate selection, so a stochastic candidate search cannot alter a later gate draw. The [panel audit](audit_corpus_rule_mixture_dgp.py) also checks every sampled edited document and flips both ends of every selected bracket in a paired counterfactual, then checks the edited document again.

An exploratory factorial used two previously monitored 2,000-source preview panels. Uniform arms sampled 512 distinct sources; enriched arms sampled 128 distinct sources from 141/173 eligible four-family sources. Each policy used the same selected source set for independent and coupled gates, `p=.5`, one seed, and `c=.4` in the coupled arm. There are zero overlapping full-source hashes between the two panels; a new untouched source range and near-duplicate screen are still needed for a final model comparison.

| Panel | Source policy | Sources | Documents with ≥2 active families, independent → coupled | Bracket + literal jointly active / jointly eligible, independent → coupled |
|---|---|---:|---:|---:|
| 130k | Uniform | 512 | 8 → 19 | 2/17 → 10/17 |
| 140k | Uniform | 512 | 18 → 19 | 11/36 → 12/36 |

| 140k | Multitask | 128 | 32 → 53 | 19/69 → 26/69 |

The selected enriched panels show the intended increase in multi-rule active documents under correlated gates. The uniform panels have few jointly eligible cases, so their realized coupling effect is noisy. These finite-sample counts do not equal the marginal probabilities exactly, and source selection changes document composition. In the 128-source enriched independent arms, only four list sites appeared per panel; that family is too sparse for a learning claim here.

The sampler can also condition training draws on an absent whole-rule combination. In a [128-source 130k pilot](results/corpus_rule_mixture_130000_multitask_bracket_copy_holdout.json), `excluded_pair=(bracket,literal_copy)` produced **zero** jointly active documents while retaining 48 bracket-active and 28 literal-copy-active documents. It required 26 gate redraws; those redraws alter the conditioned marginal law, so the holdout arm must not be described as having the original .5 marginal rate. The separate unconstrained 140k panel contains joint cases for evaluation. This is a sampling/holdout check, not model transfer evidence.

The text remains almost entirely sourced from natural documents: 0.008–0.030% of characters changed in the eight pilot arms. On first-100-word windows, the transformed uniform arms have repeated cross-document trigram share .044/.045 and the enriched arms .017/.015, equal at reported precision to the same sources before edits. That equality is expected because the audit's word-trigram metric ignores the punctuation and digit edits; it is **not independent evidence that the transformation is semantically or stylistically natural**. The natural source provides surface form by construction. Literal-copy site windows have higher repeated word-trigram shares because repeated codes are part of the selection condition; paired unedited-source windows are recorded alongside them. No source text or generated prose is committed.

**Next experiment:** build a larger source-disjoint training cache with both prevalence regimes, a frozen token budget, and whole-combination holdouts. Train small bilinear models with full-token CE and separately reported site weighting. Gate each rule by held-out full-vocabulary prediction and supported counterfactual edits before applying weight-only canonicalization, sparse-gauge methods, or supervised intervention objectives. Compare those methods at matched functional fidelity and graph sparsity. In parallel, continue the fully sampled semantic document/world-state plus corpus-calibrated compositional-syntax generator; this natural carrier cannot reveal all of the semantic rules in ordinary prose or supply a full symbolic oracle.
