# First-layer source sufficiency on the variable-length bracket model

This tests whether the newly competent one-block bilinear model has a small **functional** attention-source circuit for bracket closing while retaining its earlier joint-rule verb behavior. It does not optimize or prune model parameters. The source executor in `eval_nested_source_sufficiency.py` computes each head/key contribution from the trained embedding, per-token RMSNorm, two QK branches, RoPE, value projection, and output projection, then applies the residual, final RMSNorm, and language head. This is an exact weight-derived factorization of the first layer, evaluated on observed prefixes. Native last-position logits replay to maximum absolute error **8.6e-6** on the main panel.

For each original/edited bracket pair, a ranking picks the top K past positions **per head** on the original prefix and holds that mask fixed for the edit. Four ranking rules use absolute QK-score product, output-vector norm, known closer logit contrast, or random numbers. A fifth ranks each source by the KL change caused by deleting it alone from the native output. The closer-contrast rule uses ground-truth answers and is supervised; the other nonrandom rankings need the model and prefix but no labeled examples or fitted input distribution. All sparse predictions recompute the final RMSNorm, so nonlinear effects of combining the retained sources are included. The main panel contains 254 inner and 474 outer relevant edits, their 728 matched no-effect controls, and 512 separately sampled verb sites (seed 20261204). The average bracket prefix has 72.2 positions; K=8 retains roughly 11% of source slots per head at that average length. Exact generator probabilities define verb KL and bracket edit targets.

| Ranking and K/head | Inner relevant edit L1 | Outer relevant edit L1 | Verb oracle KL | Interpretation |
|---|---:|---:|---:|---|
| Native model | about .007 | about .003 | .2597 | Full reference |
| No attention sources | 2.000 | 2.000 | 2.5600 | Direct residual alone fails |
| Score magnitude, 4 | 2.704 | .0056 | .3013 | Outer succeeds; inner breaks |
| Score magnitude, 8 | **.0163** | **.0033** | **.2587** | Both closers and verbs retained |
| Score magnitude, 16 | .0095 | .0024 | .2587 | Smaller approximation error |
| Random, 8 | 1.894 | 1.852 | 2.1718 | Matched source count fails |

For score magnitude at K=8, the inner and outer no-effect controls have edit L1 .0017 and .0002. Both relevant edited answers remain 100% top-1 correct. At K=4, inner edited answers are only 78.4% top-1 correct, and teacher-to-reduced KL is 2.629 at inner sites, compared with .0097 at K=8. Merely counting selected opener positions does not explain this threshold: K=4 includes the relevant inner opener in an average 31.1% of heads, while K=8 includes it in 46.7%. The masks are chosen per input, so this is a **local dynamic source reduction**, not one globally fixed sparse circuit.

The independent seed-20261207 panel (136 inner and 256 outer relevant edits; 256 verb sites) replicates the main pattern. At K=4, score-magnitude inner edit L1 is 2.674, outer .0039, and verb KL .295 versus native .248. At K=8, these become .022, .003, and .247. Single-source output-KL ranking does not rescue K=4 (inner edit L1 **2.692**); K=8 reaches .010. The known-answer closer-contrast ranking likewise leaves inner edit L1 .318 at K=4 and .196 at K=8, despite preserving outer edits. This is evidence that individual-source importance is not enough to choose a four-source bundle for the inner task. The result is compatible with cancellations or complementary source combinations, but these rankings alone do not identify the mechanism.

Changing the generator's extra-filler probability at evaluation from the training value .5 to .2 or .8 changes the mix of span lengths without changing the conditional closing rule. On independent 256-stream panels, score-magnitude K=8 inner/outer edit L1 is .010/.002 at .2 and .012/.003 at .8. Verb oracle KL at K=8 is .264/.271, versus the native model's .264/.273 on those panels. K=4 still fails inner edits (L1 2.652/2.640). This is a limited mixture-rate shift, not a test of new span lengths, deeper stacks, or natural language.

The strongest present result is **behavior-preserving local compression** at K=8, with a replicated sharp failure at K=4. It is not a unique canonical form, a globally sparse parameterization, or a readable named path. Next, test joint subset selection or source-pair interactions for the inner-close computation and compare to a fixed weight-only token-pair basis. Any optimized reduction should be evaluated on disjoint bracket and verb panels, with oracle prediction, teacher fidelity, and causal edit fidelity reported separately.
