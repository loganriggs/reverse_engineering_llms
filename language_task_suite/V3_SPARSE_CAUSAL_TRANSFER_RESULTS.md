# Balanced edit-effect supervision for sparse verb/object students

Can task-balanced causal supervision make sparse transformer circuits more faithful and transferable than ordinary distillation? This first test says **not with the current output-effect objective**. On two fixed-mask 29,491-attention-edge students, adding an L1 loss on teacher probability *changes* under valid edits either substantially worsens or barely changes held-out edit-effect fidelity. Neither of the tested weights improves validation teacher-effect error relative to KL-only recovery. The result gives a stopping point for this simple loss, not a verdict on causal or path-level training generally.

The teacher is the competent two-layer, width-64 [`surface_mixture_v3_object8`](surface_mixture_v3_object8/) bilinear model. Its generator supplies exact visible-prefix distributions and grammar-valid interventions at verb and object positions. The [previous sparse-factor comparison](V3_SPARSE_FACTOR_TRANSFER_RESULTS.md) supplies a flat and a factored student, each with **29,491 active attention weights**, trained on the full toy-language mixture. We resume each frozen attention mask for 300 steps, with trainable dense embeddings and LM head, under either (a) ordinary teacher KL or (b) the same KL plus a paired-effect L1 term. The paired term compares the student's before/after next-token probability difference with the teacher's difference. It samples one pair per supervised edit family per step, so rare families cannot be drowned out by their frequency in ordinary text. The two coefficients are **0.1** and **0.01**, in separate runs; the ordinary-KL controls use the same stream seed and 300 steps within each comparison. The 0.1 run was exploratory, and the lower weight was chosen after inspecting its validation failure. The second run uses a new test generator seed but is not a preregistered confirmation.

The complete **`object_event_skip` edit family** is omitted from paired-effect fitting and validation. Fit uses 128 generated streams, validation 64, and tests 256 fresh streams. The first test contains 744 omitted-family edits; the second contains 749. Identical edit triples (kind, original prefix, edited prefix) are deduplicated across fit/validation/test; the 0.1 run excluded 0/2/13 duplicates and the 0.01 run 0/2/7. This is an **edit-supervision holdout only**. The teacher and starting sparse students already saw the underlying rule in ordinary language training, and ordinary KL recovery still draws from the full mixture. It cannot demonstrate new-task discovery or model-training transfer.

The table separates four outcomes. Validation is the equal-family mean L1 distance from the **teacher's** edit effect across the nine supervised families. Held-out teacher-effect L1 uses the omitted family. Held-out oracle-effect L1 compares the student effect to the **generator's exact** probability change; the teacher is imperfect, so these are distinct targets. Ordinary teacher KL is measured on an independent 256-stream panel. Lower is better for every column.

The 0.1 flat arm happens to improve oracle error on the omitted family while moving **away from the teacher** there and worsening its supervised-family validation error. That is not successful teacher distillation or evidence of a recovered rule circuit. At coefficient 0.01, ordinary KL is fractionally better for both causal arms, but the omitted-family teacher-effect score and supervised validation score are still worse. The expanded-object prediction panel is also not a competence test: the teacher's oracle error rises sharply on that lexical shift. For the 0.1 run, expanded-object teacher KL changes from .00368 to .00510 in the flat arm and from .00585 to .00639 in the factor arm; for 0.01 it is .00368/.00371 and .00585/.00557.

Two correctness diagnostics narrow the interpretation. Right-padded variable-length prefixes give the same last-token probabilities as the unpadded evaluator to maximum error **4.5e-7** on a probe. Optimizing the differentiable paired-effect loss on one fixed 16-pair batch decreases it from **.0509 to .0103** in 30 updates. The objective can transmit gradients. Yet the 0.1 causal flat student is worse even on representative *full fitting-panel* teacher effects: lexical .0869→.1573, induction .0327→.0432, object adjective .0710→.0981, and object induction .0397→.0429 relative to KL-only. This points to the stochastic optimization/objective balance and limited paired sampling as live bottlenecks; it does not establish a coding error or intrinsic failure of causal supervision.

Stop tuning this particular one-pair-per-family output-effect loss against the inspected test panels. The next useful design needs either a better-conditioned effect objective with larger balanced batches and in-fit validation selection **before** a fresh test, or explicit path/unit sufficiency and necessity constraints. A candidate sparse circuit must pass teacher KL, exact-oracle task prediction, and causal-effect fidelity separately, then show a small set of units or edges that is sufficient and necessary for held-out rule effects. To claim discovery, omit an entire generator rule from feature supervision and test its recovered label and intervention on unseen instances; the current experiment does not do that. More realistic toy-language forms and task coverage remain a separate prerequisite for natural-language relevance.
