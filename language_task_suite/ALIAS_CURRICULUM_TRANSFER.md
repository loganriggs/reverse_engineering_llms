# Same-vocabulary alias curriculum: a competent joint-rule checkpoint

The [original toy-language proposal](https://www.lesswrong.com/posts/GncmyuKmp526RJpmj/ambitious-mech-interp-w-tensor-transformers-on-toy-languages) asks for a known language data-generating process whose bigram, skip-gram, induction, and structural rules can interfere, followed by a test of whether interpretability methods recover those computations. Alias binding here is one added prerequisite for a *joint* lexical/induction verb prediction, rather than a replacement for that objective. The two forced definitions at the beginning of each stream make this a diagnostic curriculum, not a realistic sample of web text.

## Controlled training and holdout

The source is the 336-token, two-definition [alias stream](surface_alias_mixture.py). At each contested verb, the oracle mixes lexical, induction, lead and previous-place proposals with known weights. A short-prefix [pretrainer](pretrain_joint_alias_lookup.py) uses the **same vocabulary, 63-position context and two-layer, width-64, four-head bilinear architecture** as the joint language model. It trains for 3,000 updates on a lexical-dominant alias lookup at the verb token; the joint model then receives 3,000 updates of ordinary next-token CE plus exact-oracle verb CE. The pretrainer's own held-out alias–person pair bucket has KL **.0526** nats and query-switch TV **.979** against oracle TV **1.000**. This establishes a learned lookup skill on the same model shape, not full-language competence before fine-tuning.

For the strict transfer model, `(alias_index + person_index) % 4 == 0` pairs are absent as *definitions* from both stages' training generators. A 1,000-stream [audit](surface_alias_two_def_pair_restricted_audit.json) checks that restriction and the exact prefix oracle. Evaluation uses the unrestricted generator, so its excluded-pair subset is a genuine held-out combination test. The model has one training seed; two independent stream seeds check the same checkpoint, not training-seed robustness.

The alias-switch oracle TV is **.556/.560** on those full panels. On the pair-restricted model's *genuinely held-out* key-switch examples, model TV is **.476/.479**, versus oracle TV **.554/.544** (`n=537/530`). Swapping the aliases in their definitions changes its output by TV **.557/.568** versus oracle **.580/.569** (`n=272/272`). It still changes under an identity-preserving alias-to-canonical-name edit (TV **.172/.172** on the held-out subset, oracle zero); the learned binding is useful but imperfect. The equal-update scratch control is unrestricted; a matched restricted scratch control and more training seeds remain needed before attributing the advantage uniquely to the curriculum.

## Local interpretation gate

At the final block's last-position attention-output input, replacing the edited activation with its original value removes **93%** of the model's alias-switch effect and approximately **100%** of its relevant-definition and alias-label-swap effects. The same site mediates **93%**, **100%**, and **100%** respectively on the excluded pair subgroup. At the first block, patching all positions removes **96%** of the relevant-definition effect but only **11%** of the alias-key switch effect. These are local mediation results, not a full route through heads or a unique circuit. See [complete-bond patch results](surface_alias_two_def_pairholdout_pretrained_bilinear_v1/bond_mediation_layer1_last_seed20261108.json).

The [held-out-pair bond-basis comparison](surface_alias_two_def_pairholdout_pretrained_bilinear_v1/bond_bases_layer1_cpu_seed20261110.json) fits bases on allowed-pair streams only and tests first post-definition uses on excluded pairs (`96` tests per edit, `576` total). It compares data-free local weight SVD, composed all-output and known-verb output priors with activation PCA, edit-response SVD, and random directions. At width 16/64, the known-verb output basis has mean TV **.018** from the full model's predictions and alias-switch effect L1 error **.046** from the full effect; local weight SVD has TV **.098** and effect error **.211**. The verb-output basis uses supervised task knowledge, and 16 dimensions approximately match the verb set size. Neither finding names a human-readable binding variable. Full-width replay is verified; local truncation fidelity is separate from causal selectivity and discovery. The larger GPU run exited with code 139 during its random-basis control; the completed CPU panel is the reportable run.

## Decision point

This branch passes a competence gate for *one* binding-dependent rule collision. The next method comparison should require selective effects on held-out key switches **and** identity-preserving/irrelevant-definition controls, then test whether a basis discovered on this collision transfers to another contested rule or task family. Stop alias-specific tuning after a restricted scratch control and training-seed replication. The original proposal's broader test remains recovery of several deliberately interfering rules, including the old bigram, skip-gram, induction and bracket mechanisms, from a jointly trained tensor-transformer. Report oracle KL, causal edit fidelity, bond reconstruction and rule discovery separately.
