# Sparse-gauge comparison on competent bilinear toy-language tasks

The [v6 source-binding model](SURFACE_MIXTURE_V6_RESULTS.md) ignores its query key, so compressing it cannot establish a source-binding feature. This comparison returns to two previously trained three-layer, width-64, attention-only bilinear language models that **do** perform FAQ place recall and copying. Their native FAQ-recall oracle KL on the current 1,024-stream panel is **.102/.117 nats** for seeds 0/1, and their native recall causal-edit L1 error is **.151/.166** on 97 supported edits. The task still has simple templated text and a large [FineWeb realism gap](MULTI_GENRE_RESULTS.md); the result tests interpretation methods on a controlled model, not natural-language transfer.

`eval_multi_genre_sparse_gauges.py` fits bases at the **last attention pre-output bond** (layer index 2). Activation-based bases see **512 Reports/Policy streams** (36,352 bond vectors) and no FAQ or Guide streams. The model itself was trained on all four genres. The candidates are native physical axes, activation PCA, activation varimax, weight SVD, weight varimax, and three seeded random orthogonal bases. Each is a full-width orthogonal change of coordinates; keeping the top 16 absolute coordinates per token is the same lossy sparse gate for every basis. Full-width rotations reproduce the native logits within the numerical assertion threshold. Fit, test, and edit streams use distinct seeds. The test has **320 FAQ-recall sites** in 1,024 streams and **97 FAQ-recall causal edits** in a separate 512-stream panel, along with copy, policy, and list sites. Both trained-model seeds use exactly the same fit/test panels.

The oracle KL column evaluates the **gated model against the generator**, while model→gate KL measures faithfulness to the native model. The edit L1 column compares the gated model's probability change under a valid single-token historical-place edit with the exact oracle change. Lower is better for these columns and bond MSE; higher axis purity is better only as a post-fit signature proxy. Native FAQ-copy edit errors remain near .03/.06 at 16 coordinates and do not distinguish the bases nearly as much. At 32 coordinates most bases improve, but physical still has the lowest or nearly lowest recall model→gate KL and edit error in both seeds.

The result is a **task tradeoff**, not a universal ranking. Activation varimax makes the bond sparser in reconstruction terms and preserves in-fit Policy effects better, yet the native coordinates retain held-out FAQ recall better. The equal-family axis-purity diagnostic, computed only after fitting on disjoint edit streams, rises from **.664→.743** and **.737→.805** under activation varimax. That suggests more separated local response energy, but it does **not** predict better causal transfer. `eval_multi_genre_sparse_axis_signatures.py` also records each edit family's top-axis energy and the nuisance-person response. Axis energy alone may reflect a change that the full model later cancels; the edit-based output scores are the stronger test.

An all-genre activation-fit control uses the same 512 fitting streams but includes FAQ and Guide. At 16 coordinates, FAQ-recall model→gate KL for varimax changes from **.0279→.0137** in seed 0 and **.0500→.0638** in seed 1; recall-edit L1 changes **.239→.211** and **.413→.419**. Physical axes stay at **.0067/.0156** model KL and **.135/.256** edit L1. This control changes the allocation of fitting streams across genres as well as their task coverage, so it does not isolate a pure sample-size effect. It rules out a simple claim that giving varimax any FAQ examples reliably closes the gap.

These are **sample-dependent top-coordinate gates**, unlike the earlier fixed-rank SVD projection in [multi-genre bond gauges](MULTI_GENRE_RESULTS.md); the two interventions should not be equated. This experiment has two trained-model seeds and one final bond, and it does not recover an end-to-end FAQ circuit or establish stable cross-seed coordinates. Its useful decision is narrower: on this competent held-out FAQ task, optimizing activation sparsity or post-fit task-axis purity did not beat the native basis on causal fidelity. A more complex block-sparse/shared-dictionary featurizer needs to clear that native-axis baseline at matched active dimension and model fidelity, with whole-task fitting holdouts retained. The stopping criterion for this local rotation sweep is met; further penalty or varimax tuning on these same panels would make them a development set rather than a transfer test.
