# The bracket/verb score-mode split recurs in a second trained model

The [first-model mode study](NESTED_BASIS_MODE_ABLATION_RESULTS.md) found one rank-8 score-basis key mode needed for bracket effects and a different query mode important for verb behavior. That could have been peculiar to one initialization. We therefore trained a second one-block, four-head, width-64 bilinear attention-only model from seed 1 on the same exact-oracle variable-length joint-rule/bracket generator (1,500 steps, batch 32, length 128, RMSNorm, verb and nested-close auxiliary weights 1). Its checkpoint and all evaluations are in `surface_mixture_v2_nested_varlen_depth1_seed1/`. This is an **independent model seed**, not a new task or a realistic language corpus.

The second model passes the capability gate. On its 256-stream model evaluation panel, verb KL is **.2905**, induction-verb KL **.3343**, deterministic inner-close KL **.0011**, and outer-close KL **.00035**. A fresh 512-stream valid-edit panel contains 245 inner and 488 outer relevant opener edits, each with a no-effect control. Inner/outer relevant effect L1 is **.0066/.0010**, edited closer accuracy is 100%, and the corresponding control L1 is .0039/.00008. Thus there is a competent behavior to decompose, albeit verb prediction is weaker than in the first seed.

The shared rank-8 token-score basis uses 2,048 unlabeled fit streams and a disjoint 256-stream edit panel. The full weight-derived table replays outer-site teacher probabilities with mean KL below `1e-7`; the rank-8 mode decomposition replays its projected table to maximum absolute error `3.8e-6`. On 253 outer-edit cases, a basis with **uniform** vocabulary weighting has edit L1 .0454, a basis weighted by **unlabeled nested-stream frequencies** has **.0021**, and a basis weighted by equally many **no-bracket** streams has **1.079**. At rank 16, the corresponding errors are .0117/.0011/.955. The no-bracket failure is therefore not limited to rank 8 in this seed. On 256 verb sites, native KL is .2923 and the nested-weighted rank-8 basis has .3045; the basis preserves bracket behavior better than the full verb distribution.

A new development scan again picks **head 1, key mode 0** as the most outer-bracket-damaging mode and **head 0, query mode 0** as the most verb-KL-damaging. On a separate 256-stream bracket holdout (250 outer, 132 inner edits) and 256 verb sites:

| Functional mode removal | Outer edit L1 increase | Inner edit L1 increase | Verb KL increase | Outer edited accuracy |
|---|---:|---:|---:|---:|
| Head 1, key 0 | **+2.018** | **+2.303** | +.0036 | 34.4% |
| Head 0, query 0 | +.0003 | −.0007 | **+1.027** | 100% |
| Development-selected low-impact control | <.0001 | <.0001 | ~0 | 100% |

The rank-8 baseline has outer/inner edit L1 .0024/.0055 and verb KL .2952 on this holdout. The bracket-mode ablation is less devastating to outer edited accuracy than in the first model (<1%), so the quantitative role differs despite the same axis index. Its verb KL changes little and its six grammar-valid verb-edit families remain close to baseline. The verb-mode ablation instead worsens lexical edit L1 from .438 to .919, cue .305 to .780, and induction .369 to .504, while leaving bracket edits intact. Its place-skip effect changes less (.382 to .406); the mode is not a complete verb circuit.

Restricting head-1 key-0 removal to `(` and `[` **key-token columns** raises outer/inner edit L1 by 1.688/2.189; removing it from other key columns raises them only .097/.489. This again localizes much of the effect to opener tokens, though less exclusively than in the first seed. A random-rotation control leaves the complete rank-8 score function unchanged before ablation. On a new 64-stream panel, the canonical head-1 key basis concentrates outer damage in one axis at **2.003**, above the largest axis in each of 16 random rotations (maximum 1.896). The canonical head-0 query basis concentrates verb-KL damage at **1.024**, above the random-rotation maxima (at most .737). This repeats the first model's direction while remaining a finite random-gauge test, not a uniqueness proof.

The strongest conclusion is that **the same metric and two task-dissociated head/axis positions recur across two independently trained competent models**, with independent unlabeled fits and disjoint development/holdout interventions. It is still one small architecture and one bounded, unrealistic synthetic grammar. Head-number recurrence could reflect shared initialization and architecture conventions; it does not show that natural-language bilinear transformers use the same modes. Next test a broader joint task mixture or a deeper model, and ask whether sparse parameterization or a learned gate can expose these functional components while preserving whole-task and causal holdouts.
