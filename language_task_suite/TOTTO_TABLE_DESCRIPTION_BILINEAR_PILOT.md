# Table-to-description bridge for the language DGP

The objective is a varied, human-written language distribution with known local rules on which small bilinear language models can be trained and then interpreted **only if they learn the rules behaviorally**. ToTTo supplies structured Wikipedia tables and human-corrected single-sentence descriptions. This adapter is a bridge toward a document-level sampled DGP, not itself the full symbolic generator or an all-token next-token oracle.

## Distribution and rule sites

For each eligible ToTTo train record, the adapter selects one highlighted table row and presents the page title, section, a complete header row, and that row, followed by `Description: ` and the human-corrected sentence. The local rule site is an exact, unique occurrence of a highlighted cell value in the sentence. At least two such values must come from distinct cells. The visible-text validator verifies that the stated value appears under the stated header. The model trains on every non-padding next-token target, with tenfold weight on the marked value tokens.

For example, a record about Brian Ebersole displays `Opponent: Chris Lytle` and `Event: UFC 127`, followed by “Ebersole made his UFC debut against Chris Lytle at UFC 127.” Another record displays `Year: 1994`, `Title: Kotreshi Kanasu`, and `Role: Kotreshi`, followed by a sentence about Vijay Raghavendra playing Kotreshi in 1994. The selected sentence can contain facts not shown in the single displayed row, so exact value sites are the only verified labels.

The full official training release has 120,761 records. The first adapter accepted 27,486 examples with two exact mentions. Manual inspection found ragged table rows where omitted leading cells shifted all column names; for example a `Mr. Broadway` cell was incorrectly put under `Year`. The corrected adapter requires an explicit complete header row with the same width as the data row, rejecting that case. It retains 21,165 examples across 15,323 distinct pages, with 59,523 marked sites. 58,792 sites align to GPT-2 token boundaries and fit within a 256-token context; 20,489 examples have all sites usable. This is a structural check, not a certificate that every sentence claim is entailed.

A reservoir sample of 512 accepted sentences has 13.6 mean words, 28.5% top-ten word share, and 13.7% cross-document repeated-trigram occurrence share. The corresponding random sample from all ToTTo training sentences has 13.5 words, 28.4% top-ten share, and 11.0% repeated-trigram share. The selected material is somewhat more repetitive than the broader ToTTo source, but substantially less repetitive than the earlier synthetic semantic-tree control (83% repeated trigrams). The comparison is genre- and length-sensitive; these figures alone do not establish a FineWeb match.

## Splits and behavioral gate

The corrected local cache is `artifacts/totto/totto_table_description_cache_v2.pt` in the neuron_circuits workspace. It has 13,165 training examples, 1,725 validation, 1,684 test, 354 combination validation, and 383 combination test. The split hashes page URL, keeping pages disjoint. All training rows with both visible `Title` and `Year` columns are removed; combination evaluation requires both columns to be marked target sites. Each column occurs separately in training. The cache contains source text and remains local.

The original, *incorrectly aligned* cache was used for a depth-2, width-64, four-head RMS bilinear pipeline pilot. It trained for 5,400 steps before interruption. At 2,400 steps, the ordinary page-disjoint test sample of 128 rows had 5.21 token NLL, 6.5% first-BPE top-1 at marked sites, and 1.8% full-phrase top-1 under teacher forcing. At 5,400 steps, these were 8.0% and 2.7%. On the selected-site Title+Year combination test, full-phrase top-1 was 0.8% at 5,400. The trend shows language loss learning, but not competent value binding, and the wrong column alignment invalidates any task-family or circuit conclusion.

On the corrected v2 cache, the same depth-2, width-64, four-head RMS bilinear model trained for 6,000 steps at batch size 4. At 6,000 steps, the fixed 128-row page-disjoint test sample has token NLL 4.78 and marked-site token NLL 6.82; first-BPE top-1 is 7.8% and full-phrase teacher-forced top-1 is 1.9%. The Title+Year combination test has 3.1% first-BPE and 2.1% full-phrase top-1. Accuracy at **all** marked sites in a row is 0% on every split. This model has learned substantial ordinary language statistics but has not passed the rule-behavior gate. These are small fixed evaluation samples and a single seed, so the exact percentages should not be treated as stable population estimates. The low accuracy is decisive enough to defer weight interpretation of this model.

The behavioral gate is full-phrase value accuracy (with teacher forcing explicitly labeled), first-BPE accuracy, and a future paired value-swap test. A component is eligible for weight-based interpretation only after it demonstrably predicts the intended value rather than merely common sentence tokens. No sparse-weight, canonicalization, or causal-fidelity result is claimed from this pilot.

## Decision

Keep ToTTo as a natural-language rule bridge and a negative control for table-to-sentence binding at this capacity/budget. Do a paired value-choice check before deciding whether any apparent site accuracy reflects the displayed table. Do not extend this one architecture with an open-ended step sweep. Continue the main direction with jointly sampled document semantics and varied corpus-attested syntax: several rules in the same document, explicit source/world state, and whole-task/combination holdouts. Compare weight-based sparsification or canonicalization only on behaviors actually learned. The main research question is whether such methods reveal underlying rules across DGP hyperparameter changes, not whether one model achieves the best language-model loss.
