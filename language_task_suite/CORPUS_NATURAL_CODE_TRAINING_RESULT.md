# Training on natural code repetition: source signal, partial transfer, interference

The [source-dependence gate](CORPUS_NATURAL_CODE_SOURCE_DEPENDENCE_RESULT.md) found that models trained on three-piece fictional aliases did not use naturally repeated, single-token codes. This experiment continues two saved depth-4, width-128 bilinear joint models on such sites, using two independent, unseen-source test panels. It separates natural training from a source-scrambled control and an explicitly enriched paired-edit condition. The goal is to decide whether natural code repetition can become a third **learned** rule for weight-based interpretation.

The [trainer](train_corpus_natural_code_source_control.py) draws 1,194 strictly aligned source documents from 20,000 unconditioned FineWeb sources at offsets 393k–413k. One ordinary nonoverlapping 256-token chunk per selected source has a previous code and later one-token repeat in view. All conditions use the same starting checkpoint within seed, 2,000 AdamW updates, batch eight, learning rate `1e-4`, target weight 200, and next-token cross-entropy from chunk start through the target. The conditions differ only in the selected code signal:

* **Natural:** unedited source and its natural later code.
* **Source-scrambled:** prior code occurrences are consistently substituted, but the target label stays the natural code. Target frequencies are therefore identical to the natural condition, while the earlier-code identity is no longer predictive. Other prefix token labels match the substituted prefix.
* **Paired edit:** natural and consistently substituted versions of each training source, each with its matching target. This is an enriched alternate-world distribution, not unedited FineWeb. It has two rows per source but the same batch and update budget.

The two held-out panels contain 317 and 334 paired documents from FineWeb offsets 383k–393k. Their sources never occur in training. They test the natural document and a diagnostic consistent-code edit. The panel has 262/274 source–edit code pairs absent from the training cache, and 38/41 source codes entirely absent from the selected training sites. A fixed code-frequency predictor cannot get both paired two-choice answers right because the correct answer changes between arms.

Natural-prefix training induces a reproducible source-specific response above the source-scrambled control, but most edited answers still fail. The paired condition makes the response much stronger and transfers to **new code combinations**: strict paired two-choice is .508/.464 for seed 72104 and .477/.423 for seed 72105 on those subsets. It does not transfer exact answers to entirely unseen source codes: strict paired two-choice is at most .026 on the 38/41 such cases in either seed. Positive edit-response direction alone overstates copying, since it remains above .89 even on unseen-code subsets while exact paired answers are zero. The training-source probe exposes memorization: natural-condition models predict the unedited target top-1 on about 98% of their training sources, versus roughly 1–5% on held-out natural targets. Full per-split numbers are in [seed 72104](results/corpus_natural_code_source_control_seed72104_s2000.json), [seed 72105](results/corpus_natural_code_source_control_seed72105_s2000.json), [paired seed 72104](results/corpus_natural_code_paired_seed72104_s2000.json), [paired seed 72105](results/corpus_natural_code_paired_seed72105_s2000.json), and the [training-source probe](results/corpus_natural_code_source_control_trainprobe_393000_5000.json). Checkpoints and reconstructable token caches remain local.

The code-only continuation also interferes with the other learned rules. On two fresh ordinary-order list/bracket panels, the starting joint models get list paired exact top-1 .960/.918 (seed 72104) and .980/.984 (72105). After paired code training these fall to .200/.213 and .460/.541. Bracket paired correct-closing-character falls from .837/.843 to .534/.557 and from .821/.807 to .401/.398. Bracket two-choice remains relatively high, which again would conceal the full-vocabulary and character-level degradation. Selected bracket-chunk background CE rises from about 7.18–7.23 to 7.67–7.71. See [retention panel one](results/corpus_natural_code_paired_list_bracket_retention_363000.json) and [panel two](results/corpus_natural_code_paired_list_bracket_retention_368000.json).

**Decision:** natural repeated-code training supplies a measurable source-use signal, and paired edits improve it, but these continuations are not yet strong three-rule models or suitable weight-circuit targets. The next experiment should jointly train code, list, and bracket examples with a declared mix, preserve an unconditioned natural-reference evaluation, and keep held-out source-code identities and combinations separate. More source documents or a tokenizer/architecture that composes unseen code strings may be needed for genuine open-code copying. Any sparsity or canonicalization method must be tested only on rules that pass exact behavioral and causal gates in that joint model. The paired edit condition is a training intervention, not a claim that all its text is natural web data.
