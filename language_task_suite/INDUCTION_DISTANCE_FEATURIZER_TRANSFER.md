# Short-to-long induction response transfer at a bilinear attention bond

The [dependency audit](DEPENDENCY_PROXY_REALISM_AND_REPEAT_TRADEOFF.md) introduced a subject-return distribution that preserves frequent exact induction sites while moving most source verbs beyond the immediately preceding sentence. Its trained two-layer bilinear model has a partial long-range causal response, so it permits a bounded interpretability test: can a compact basis learned from **short** induction interventions retain the model's **long** induction effect at a causally relevant bond?

`eval_v2_induction_distance_transfer.py` uses the model in `surface_mixture_v2_repeat01_return03_soft_models/`, trained with repeat mass 0.1 and return mass 0.3. It takes exact-oracle, grammar-supported historical-verb edits from the same DGP. The fit set has source distance at most 24 tokens and uses `lead`, `subject`, and `at` frames from seed 9901. The test set has source distance above 24 and uses `when`, `in_place`, and `during` frames from seed 8701 or 8702. The reverse split swaps frame sets. A separate long-distance fit set from seed 9901 is an informed control, not a guaranteed upper bound. The language model itself was trained on all frames and distances; only **basis fitting** holds out long-distance examples and sentence frames.

The measured vector is the activation immediately before the final attention output projection at the last prefix position. We patch the original prefix with the complete edited-minus-original vector and then with projections of that vector into eight-dimensional bases. The full patch almost recovers the model's edited prediction on held-out long-distance pairs: full-patch-to-model effect L1 error is 0.019–0.022 across the four runs. This makes the site appropriate for a *local model-effect* comparison. It does not show that this bond contains the complete oracle rule, or that a single-position patch captures every path.

The table reports projected-patch-to-**full-local-patch** effect L1 error, lower being better. All bases have width eight. The weight prior is the top 32 right singular directions of the attention-output weight matrix; the subsequent eight-direction fit uses only short intervention responses. Activation PCA uses a separate ordinary-activation fit stream. Quartimax rotates the same 32-dimensional weight prior using short induction responses, then selects eight axes by short-response energy. These responses identify the known induction intervention family; the rotation is unlabeled only *within* that family.

The rank ordering is stable across test streams and frame directions: short-edit supervision transfers substantially better than generic weight or activation energy, and the weight-derived 32-dimensional prior helps slightly at width eight. The quartimax sparse-axis objective does *not* improve on the short-edit SVD here. The long-edit control sometimes loses to short-edit fitting, so it should not be read as an upper bound.

The most distant subset is smaller (65–96 edits per split). On seed 8701, for sources beyond 48 tokens, the short-edit SVD versus weight-prior-then-short-edit errors are .079/.068 forward and .068/.065 reverse; raw weight SVD gives .133/.105. The full patch still closely matches the model (.018/.014 L1 error). But the **native model-to-oracle** effect L1 errors are .407/.426 on those subsets, versus .500 for a zero-effect predictor. The decomposition preserves a *partial model computation*, not the exact DGP computation. That gap is the stopping criterion for claiming a long-range induction circuit in this checkpoint.

This is not a whole-rule-family training holdout or new-task discovery. Its value is methodological: weight-only reduction plus a small supervised causal basis can transfer across a controlled dependency-distance shift at a bond that passes a full-patch gate. The next step in the larger loop is a more competent, structurally varied multi-task language model, then the same weight-only/data-aware/sparsity comparison on **held-out rule families or combinations** with separate reconstruction, task KL, and causal-fidelity scores. Repeatedly rotating this one partial induction response would not answer that question.
