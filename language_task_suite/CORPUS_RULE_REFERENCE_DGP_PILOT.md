# Unconditioned source-document rule stream: pilot

The earlier three-rule model was trained on task-centered FineWeb windows. Its lexical statistics were close to random FineWeb crops, but numbered lists occurred in 26% of its windows versus about 1–2% in the reference crops. This pilot samples source documents without requiring a task, keeps their original order, and cuts ordinary nonoverlapping 256-token model chunks. It measures the supervision this reference distribution actually offers; it has not yet trained a model.

The [sampler](corpus_rule_reference_dgp.py) recognizes one eligible numbered-list site, one matched parenthesis site, and one repeated three-letter entity code site per document when present. The default **natural reference arm** keeps the source text unchanged. It tags a list's next number and a closing parenthesis, but does not introduce fictional aliases. The **enriched diagnostic arm** may shift a list by one, change a selected parenthesis pair to square brackets, and replace a repeated acronym-like string with a sampled same-length code. Each edit preserves character length, so sites from different families can coexist without moving their offsets. The [checks](check_corpus_rule_reference_dgp.py) verify visible-prefix answers, three-rule composition, BPE alignment, and chunk-local labels.

All training positions in a chunk receive ordinary next-token targets. A rule site receives a separate label only when its source and answer both fit that same chunk and its answer aligns with the tokenizer. Ordinary prose tokens have no exact symbolic next-token oracle. These local counts are lower bounds on sites available to a model that retains state across chunks. This is a source-level stream, not an exact-probability synthetic language.

The enriched rates are list 1, bracket 1, nonce 1, list-shift .5, and square-bracket .5, conditional on eligibility. These are experimental settings, not estimates of natural occurrence rates. In the second enriched panel, 24 documents have a local list+bracket pair, 27 bracket+nonce, and one list+nonce; one document has all three. In the natural panel, 24 documents have both local list and bracket sites. The natural panel yields 13,577 chunks and 2.85 million valid next-token positions from 5,000 sources, but only 54 local list sites. Unconditioned small-model training will therefore need many more sources or task loss weighting for lists; enriching task windows changes the training distribution and must be reported as such.

A local-only review of transformed excerpts found that shifting an ordinary `1,2,3` list to `2,3,4` can make the surrounding document odd, and an invented acronym can alter factual meaning. The unedited reference avoids those issues. Shift, delimiter-style, and alias arms remain useful as controlled counterfactuals, not as claims that their surface text is authentic web prose. Aggregate JSONs contain no source prose: [enriched panel one](results/corpus_rule_reference_pilot_start353000_n5000.json), [enriched panel two](results/corpus_rule_reference_pilot_start358000_n5000.json), [natural panel](results/corpus_rule_reference_natural_start358000_n5000.json).

This pilot does not establish model competence, source-level near-duplicate separation across eventual train/test partitions, or interpretability of learned weights. The next decisive step is paired, fresh-source evaluation of the already trained joint models in ordinary document order: compare each unchanged list/bracket source with its valid counterfactual edit, score exact full-vocabulary predictions and causal response at visible sites, and report background next-token loss separately. Only learned rules that pass those behavioral checks should be used as targets for weight-based decomposition or sparsification. A larger source-unconditioned training run should follow if the reference transfer fails for lack of rule exposure.
