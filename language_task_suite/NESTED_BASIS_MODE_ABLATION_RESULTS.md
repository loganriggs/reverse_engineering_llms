# Two stable first-layer score modes separate bracket and verb behavior

The [shared token-basis experiment](NESTED_SHARED_TOKEN_BASIS_RESULTS.md) found a stable rank-8 first-layer score basis, but low-rank fidelity does not establish that its individual directions are meaningful. Here each query or key axis is removed from the projected `QK1 × QK2` token-pair score table **across all relative lags**, leaving the other score modes, token values, residual, final RMSNorm, and language head intact. This is a functional score-tensor intervention, not a native weight edit or proof that the model contains an independently gated node.

`eval_nested_basis_mode_ablations.py` checks that summing the eight query contributions, or separately the eight key contributions, reconstructs the rank-8 score table to maximum absolute error below `4e-6`. It fits the basis from 2,048 unlabeled nested-stream sequences, scans all 64 head × side × mode ablations on a separate development panel, and preselects the modes with largest outer-bracket edit damage, largest verb KL damage, and smallest combined damage. These selections are tested on fresh bracket-edit, verb-prediction, and grammar-valid verb-edit panels. The complete protocol repeats with a second frequency fit and new panels. Both scans independently select **head 1, key mode 0** for bracket damage and **head 0, query mode 0** for verb damage.

| Holdout and intervention | Outer edit L1 increase | Inner edit L1 increase | Verb oracle KL increase | Outer edited accuracy |
|---|---:|---:|---:|---:|
| Seed 20261223, remove head-1 key-0 | **+2.699** | **+2.068** | −.0005 | 0.4% |
| Seed 20261223, remove head-0 query-0 | ~0 | ~0 | **+.822** | 100% |
| Seed 20261227, remove head-1 key-0 | **+2.651** | **+2.081** | +.0001 | 0.9% |
| Seed 20261227, remove head-0 query-0 | ~0 | +.0005 | **+.806** | 100% |

The rank-8 baseline has outer/inner edit L1 .0045/.0079 and verb KL .2723 on the first holdout, and .0045/.0098 and .2757 on the second. It predicts all edited bracket closers correctly. Removing the bracket mode reduces inner edited accuracy to 3.6% on both panels. A development-selected low-impact mode provides a control: it changes outer/inner edit L1 by less than `5e-5` and verb KL by less than `.0003` on the holdouts. The selected first axes are individually stable across independent frequency fits: absolute correlations are **.99989** for head-1 key-0 and **.99947** for head-0 query-0.

The verb-edit holdouts contain 121–170 induction edits, 121–135 cue edits, 244–267 lexical edits, 349–350 place edits, and nuisance controls. Removing head-1 key-0 leaves each family's **oracle effect error** within about .005 of the rank-8 baseline. Removing head-0 query-0 raises lexical edit L1 from .409/.408 to .906/.938, cue from .337/.341 to .686/.716, induction from .384/.365 to .529/.531, and place from .345/.343 to .465/.456. It also worsens the nuisance-determiner response (.022 to .072/.085), so “verb-sensitive” means task-family concentration, not perfect selectivity. This causal edit check matters because unchanged average verb KL alone could hide a rule-effect change.

The key-mode intervention can be localized further. Subtracting head-1 key-0 **only in the `(` and `[` key-token columns** increases outer edit L1 by 2.073/2.068 and inner by 2.035/2.045 on the two holdouts; outer edited accuracy falls to zero. Subtracting the same mode from **all other key-token columns** has a smaller but nonzero effect: outer edit L1 rises .792/.809, inner .208/.189, while outer edited accuracy stays about 90%. Thus opener keys carry most of this mode's necessary bracket response, but other tokens in the same mode also matter. These column-restricted interventions were exploratory follow-ups checked on both panels, rather than part of the original development selection.

The [token profile](surface_mixture_v2_nested_varlen_depth1/selected_mode_token_profiles.json) is consistent across fit seeds. Orienting head-1 key-0 so `(` is positive, its weighted loadings on `(`, `[`, `)`, and `]` are about +.258, −.372, −.136, and +.121 (second fit: +.262, −.378, −.138, +.122). The opposite opener signs are compatible with distinguishing bracket type. The same axis also loads on `.`, `,`, `the`, and cue words, so it is not a pure named “bracket feature.” Head-0 query-0 loads broadly on subject and other lexical tokens; its causal role is clearer than its token-profile name.

`eval_nested_mode_rotation_redteam.py` addresses the gauge objection that any rotation within the rank-8 subspace represents the same complete score function. It randomly rotates the head-1 key basis or head-0 query basis, transforms the core oppositely, checks reconstruction error below `1.4e-5`, then ablates each rotated axis. On two new panels (109/97 bracket pairs and 64 verb sites each), the canonical head-1 key basis has maximum outer-edit damage **2.745/2.646**; the maximum within each of 16 random rotations averages 1.903/2.155 and never exceeds 2.326/2.575. Canonical head-0 query maximum verb-KL damage is **1.148/.952**; random-rotation maxima average .363/.255 and never exceed 1.001/.844. Thus the weighted Gram eigenbasis concentrates these sampled causal effects more than the tested random gauges. Sixteen rotations are a red team, not proof of uniqueness or global optimality.

This is evidence for a **reproducible task-dissociated functional decomposition of one trained model's first-layer score function**. The [independent-model replication](NESTED_CROSS_MODEL_REPLICATION.md) subsequently finds analogous modes in a second trained seed. Neither result establishes a unique canonical circuit, a natural-language mechanism, or broad transfer across architectures and tasks. The basis depends on the synthetic token metric; the model's bracket grammar is bounded and its surface statistics are far from FineWeb. Next, test broader joint task mixtures and whether sparse optimization can make these functional modes explicit without losing held-out rule effects.
